## Selected work

### 01 / Verdikt
**Configurable LLM evaluation for Python**

An embeddable LLM-as-judge library for evaluating model responses, RAG outputs, and agent trajectories.

- Nine built-in judge types, multi-model evaluation, five consensus strategies, and meta-judge support.
- Sequential and parallel evaluation pipelines with conditional steps and early-exit gates.
- Typed verdicts with reasoning and cost/token accounting; retries, model fallbacks, and optional caching.

**Python · LLM evaluation · RAG · Extensible interfaces**

### 02 / BolToBook
**A voice-first English and Hindi writing studio**

An evaluation beta for capturing ideas and assembling book manuscripts, with authenticated storage and a device-local guest experience.

- Next.js application backed by Supabase Auth, PostgreSQL, and private storage.
- Owner-based row-level security for writing data.
- Guest mode using IndexedDB, plus manuscript organization and template-based covers.

**Next.js · TypeScript · Supabase · PostgreSQL · IndexedDB**

[Explore repository](https://github.com/priyankadash2266/BolToBook) · [Current scope](https://github.com/priyankadash2266/BolToBook#current-scope-and-limitations)

### 03 / Omniscient
**A structured workspace for incident investigations**

A foundation release for documenting root-cause analyses, tracing evidence, and tracking follow-up actions.

- Ten-section RCA editor with Markdown import/export and completeness checks.
- Source-linked keyword evidence search and action tracking.
- PostgreSQL row-level security, atomic audited writes, and revision checks to prevent stale edits.

**Next.js · React · TypeScript · Supabase · PostgreSQL**

[Explore repository](https://github.com/priyankadash2266/Omniscient) · [Live app](https://omniscient-alpha-self.vercel.app) · [Scope and roadmap](https://github.com/priyankadash2266/Omniscient#honest-scope)
